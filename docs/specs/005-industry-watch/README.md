# Spec 005 — industry-watch（行业观察）

状态: **done**

> 后续变更: **spec 008** 将本模块收敛为「宏观经济」二级菜单项（路由 `/industry` 不变）；同时**从「国家经济数据」页移除了 `industry` 分组的重复渲染** —— 本 spec 上线时 `/macro` 会连带渲染「行业景气与高频」区段，导致 10 项行业指标在两页重复出现，现已修正（`/macro` 26 项、`/industry` 10 项，互不相交）。本 spec 正文保留当时的状态记录。

## 目标

在「数据观察」下新增行业观察模块：以实物量与价格口径补充行业视角（用电量、货运量、民航客座率、物流景气、大宗商品/农产品/建材价格），共 10 项指标（总指标数 26 → 36），首页占位卡片转为正式入口。

非目标: 不做个股/板块行情；不做分行业增加值（统计局接口被 WAF 拦截，见 spec 004 评估）；不为行业指标配置告警规则（留待后续 spec）。

## 交付

- 10 项行业指标入库（`dim = industry`），日频源按月月末采样
- `/industry` 页面 + 侧边栏菜单 + 首页入口
- 日期归一规则 `YYYY.M → YYYY-MM`、`month_end_sample`

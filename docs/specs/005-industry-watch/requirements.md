# Spec 005 — industry-watch（行业观察）

状态: **done**

## 目标

在「数据观察」下新增**行业观察**模块：以行业/实物量视角补充宏观数据（用电量、货运量、民航客座率、物流景气、大宗商品与建材价格），首页占位卡片转为正式入口。

非目标: 不做个股/板块行情（属投资视角，另立 spec）；不做分行业增加值（统计局接口在本网络被 WAF 拦截，见 spec 004 评估）；不为行业指标配置告警规则。

## 依赖

- 复用 spec 001 数据层与卡片/图表组件；指标仍走 `scripts/fetch_data.py` → 同一张 `series`/`meta` 表。
- 数据源均已实测新鲜（2026-08 / 2026-09-21）。

## 用户故事与验收标准

### US-1 行业指标入库

作为用户，我在「行业观察」看到 10 项行业与高频指标，数据为当期。

- [x] AC1: 新增 10 项指标，归入新分组 `industry`（「行业景气与高频」）：
  物流景气指数、民航客座率、铁路货运量同比、公路货运量同比、全社会用电量同比、第二产业用电量同比、第三产业用电量同比、大宗商品价格指数、农产品批发价格指数、建材指数。
- [x] AC2: 日频源（大宗商品/农产品/建材）按**每月最后一个观测值**月度化后入库，保持 36 期窗口 = 36 个月，与其它月度指标口径一致。
- [x] AC3: 日期格式 `YYYY.M`（统计局/新浪口径）统一归一为 `YYYY-MM`。

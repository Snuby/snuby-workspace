# Spec 002 — macro-alerts（跟踪提醒）

状态: **done**

> 后续变更: **spec 008** 将本模块收敛为「宏观经济」二级菜单项（路由 `/alerts` 不变），侧边栏不再单列；页首新增一句模块自述，说明判定分阈值/异动/相对比较三类、不推送通知。本 spec 正文保留当时的状态记录。

## 目标

在「数据观察」下新增**跟踪提醒**模块：对已入库的宏观指标配置阈值/异动规则，页面实时评估并展示触发状态；工作台首页的「跟踪提醒」卡片从占位态升级为实时摘要（触发数 + 最新触发项）。

非目标: 不做推送通知（邮件/webhook），不做用户自定义规则的 UI（规则为代码内配置），不做历史告警存档。

## 依赖

- 复用 spec 001 的数据层（SQLite `series` 表、`macro-service` 读取用例），无需改动数据管道。

# Requirements — 002 macro-alerts

## 用户故事

### US-1 规则评估

作为用户，系统按预置规则集对最新入库数据自动评估，我无需手动操作即可知道哪些指标出现异动。

预置规则（首批，代码内配置，见 design.md）:

- 制造业 PMI 跌破 50（荣枯线下）
- CPI 同比为负（消费通缩）
- PPI 同比为负（工业通缩）
- M1 增速低于 M2（剪刀差为负，资金活化不足）
- 失业率高于 5.5%
- 70 城房价同比为负（房价下跌）
- 出口同比环比降幅超过 5 个百分点（外需骤降）
- GDP 同比低于 4.5%（增长失速）

验收标准:

- [x] AC1: 每条规则有唯一 `ruleId`、关联指标 `indicatorKey`、严重级别（warning / danger）。
- [x] AC2: 评估基于 `series` 表最新两个数据点，规则类型为 `threshold`（最新值与阈值比较）或 `delta`（最新值较前值变化超过阈值）。
- [x] AC3: 指标无数据或数据点不足时，该规则状态为 `no_data`，不报错。

### US-2 跟踪提醒页

作为用户，我在「数据观察 → 跟踪提醒」页看到全部规则的状态列表，触发的排在最前并高亮。

验收标准:

- [x] AC1: 侧边栏「数据观察」分组下新增「跟踪提醒」菜单项，路由 `/alerts`。
- [x] AC2: 页面按状态分组展示: 触发中（danger 在前、warning 在后）→ 正常 → 无数据；每条显示规则名、关联指标名、最新值/日期、触发说明。
- [x] AC3: 页面顶部显示统计条: 触发中 N 项（danger x / warning y）· 正常 M 项。
- [x] AC4: 数据库缺失时显示可理解的错误提示，不白屏。

### US-3 首页摘要

作为用户，我在工作台首页的「跟踪提醒」卡片直接看到当前异动概况，点击进入详情页。

验收标准:

- [x] AC1: 卡片显示触发规则数；触发数 > 0 时列出严重级别最高的前 3 条规则名；触发数为 0 显示「一切正常」。
- [x] AC2: 卡片可点击跳转 `/alerts`，不再显示「敬请期待」。

### US-4 API 契约

- [x] AC1: `GET /api/macro/alerts` 返回全部规则评估结果（契约见 design.md），与页面共用同一用例。

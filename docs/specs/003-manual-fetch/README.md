# Spec 003 — manual-fetch（手动数据更新）

状态: **done**

## 背景

原每周一 09:00 定时抓取任务已取消，数据更新改为用户在「国家经济数据」页主动触发。

## 目标

在 `/macro` 页提供「更新数据」按钮：点击后异步执行 `scripts/fetch_data.py`，页面实时显示逐指标进度；运行期间禁止重复触发；完成后刷新页面数据并汇报成功/失败明细。

非目标: 不做定时调度，不做抓取日志持久化（进度状态仅存内存，服务重启即清空）。

## 用户故事与验收标准

### US-1 主动触发

作为用户，我在 `/macro` 页数据说明行点击「更新数据」按钮启动抓取。

- [x] AC1: `POST /api/macro/fetch` 启动抓取子进程；已有任务在跑时返回 409，不产生第二个进程。
- [x] AC2: 按钮点击后立即进入运行态（禁用 + 进度显示），重复点击无效。

### US-2 进度可见

- [x] AC1: 页面每 ~1s 轮询 `GET /api/macro/fetch/status`，显示 进度 n/25、成功/失败计数。
- [x] AC2: `scripts/fetch_data.py` 每完成一个指标输出一行机器可读进度（`@@PROGRESS {...}` JSON 行），Node 侧解析后进入内存任务状态。
- [x] AC3: 完成后按钮恢复可用，页面自动刷新数据，展示结果摘要（成功 x / 失败 y，失败列指标名）；失败仅个别指标不视为错误。

## 技术决策

1. **任务状态存 Node 进程内存**（单实例本地应用），用模块级单例防并发；子进程用 `child_process.spawn` + `-u` 无缓冲流式读取。
2. **防重复双保险**: 内存 `status === "running"` 拦截 + 409。
3. Python 解释器路径: env `FETCH_PYTHON_BIN`，默认 venv 路径（README 环境变量表记录）。
4. 设置页「数据更新频率」文案同步改为「手动触发」。

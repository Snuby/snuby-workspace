> 后续变更: spec 002 增加跟踪提醒模块；spec 003 取消定时任务改为手动更新；spec 004 将指标数扩至 26 并修复数据源时效；**spec 008 将侧边栏「数据观察」分组收敛为单一「宏观经济」一级菜单 + 顶部二级菜单，并把 `/macro` 收窄为 26 项宏观指标（原含 industry 分组，与「行业观察」重复渲染）**。本 spec 正文保留当时的状态记录。

## 目标

将原静态版 Snuby 工作台升级为本地 Next.js 应用：左侧菜单 + 右侧内容区，「数据观察 → 国家经济数据」展示 25 项中国宏观经济指标。数据由 Python 管道写入 SQLite，Next.js 只读，为后续模块（行业观察、跟踪提醒）预留扩展点。

非目标: 不做多用户/鉴权，不做在线部署，不迁移历史静态页。

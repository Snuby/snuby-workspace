# Requirements — 001 workbench-mvp

## 用户故事

### US-1 工作台外壳

作为用户，我打开 Snuby 后看到左侧固定菜单（Logo「Snuby」、导航分组、版本号）和右侧内容区（顶栏 + 内容），导航切换不整页刷新。

菜单结构:

```
工作台          → 首页: 模块卡片栅格
数据观察        → 分组标题
  国家经济数据  → 宏观指标仪表盘
设置            → 数据管道信息
```

验收标准:

- [x] AC1: 左侧菜单项与页面一一对应，点击切换右侧内容，当前项高亮。
- [x] AC2: 顶栏显示当前页面标题与所属分组（面包屑）。
- [x] AC3: 首页展示模块卡片；「国家经济数据」可点击进入；「行业观察」「跟踪提醒」为占位态，标注「敬请期待」。
- [x] AC4: 设置页展示数据更新频率、存储方式、数据来源三项信息。

### US-2 国家经济数据仪表盘

作为用户，我在「国家经济数据」页按维度分组浏览 25 项宏观指标，每项看到最新值、数据日期、近 36 期趋势图与口径说明。

验收标准:

- [x] AC1: 指标按分组渲染（总量与增长 / 消费与投资 / 对外贸易 / 价格 / 货币与金融 / 信心先行 / 房地产 / 汇率与外储），分组顺序固定。
- [x] AC2: 每张指标卡展示: 指标名、最新值（含单位）、最新日期、近 36 期折线图、口径说明。
- [x] AC3: 数据来自 SQLite（`data/china_economy.db`），页面加载时从服务端读取，不硬编码数据。
- [x] AC4: `GET /api/macro/indicators` 返回全部指标与序列（契约见 design.md），供后续客户端场景复用。
- [x] AC5: 数据库缺失或为空时页面显示可理解的错误提示，不白屏。

### US-3 数据管道

作为运维者，我运行 `npm run fetch` 即可将 25 项指标最新数据抓取并写入 SQLite；写入可重复执行（幂等）。

验收标准:

- [x] AC1: `scripts/fetch_data.py` 相对自身定位数据库（`<项目根>/data/china_economy.db`），无硬编码绝对路径。
- [x] AC2: 单个指标抓取失败不影响其他指标，退出码非 0 仅当失败数 ≥ 20。
- [x] AC3: 定时任务（每周一 09:00）指向新脚本路径，执行后 Next.js 页面无需构建即可读到新数据。

## 数据需求

指标清单（25 项）与口径见 `docs/conventions.md`「数据口径备忘」及 `scripts/fetch_data.py` 中的任务表。

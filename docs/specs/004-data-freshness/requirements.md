# Spec 004 — data-freshness（数据时效性修复）

状态: **done**

## 背景

2026-09 复核发现 25 项指标中有 9 项数据明显滞后（最久近 1 年）。根因：这些指标使用的是东方财富「报告式」接口（`*_yearly`，网页快讯口径，源本身滞后），而 akshare 同时提供国家统计局官方月度接口且数据是最新的。

## 目标

1. 能用官方源替换的指标，全部换成官方源，取到最新月份。
2. 无法替换的滞后指标，在界面上**显式标注滞后月数**，让读者不再误读。
3. 补一个数据新鲜的信心类指标，填补滞后项留下的维度空缺。

非目标: 不引入付费数据源（Wind/Choice）；不自己爬统计局网站；不为滞后项编造数据。

## 用户故事与验收标准

### US-1 数据源替换

作为用户，我看到的物价、生产、景气、外储数据应当是最近一两个月的。

- [x] AC1: 工业增加值、CPI、PPI、制造业 PMI、非制造业 PMI、外汇储备 6 项改用统计局官方接口（`macro_china_gyzjz` / `macro_china_cpi` / `macro_china_ppi` / `macro_china_pmi` / `macro_china_fx_gold`），最新月份 ≥ 2026-08。
- [x] AC2: 替换时清理旧源在同指标下遗留的、日期格式不一致的历史行，避免序列混排。
- [x] AC3: 新增「消费者信心指数」（月度，东财 `macro_china_xfzxx`），指标总数 25 → 26。

### US-2 时效性透明

作为用户，我能在页面上区分「这段时间还没发布」和「数据源本身滞后」。

- [x] AC1: 领域层定义滞后判定 `isStale(latestDate, freq, ref)`，容忍度按频率区分：月度 3 个月、季度 6 个月、半年度 8 个月。
- [x] AC2: `/macro` 指标卡在滞后时显示「数据源滞后 N 个月」徽标；页头汇总「其中 N 项数据源滞后」。
- [x] AC3: `/alerts` 规则项若依赖滞后指标，同样显示滞后徽标（提示该判定基于旧数据）。
- [x] AC4: 无法替换的 3 项（企业景气指数、社融增量、国房景气指数）保留并标注，不隐藏。

### US-3 口径说明落地

- [x] AC1: 指标卡「口径说明」此前为空（仓储层写死空串），改由领域层 `INDICATOR_DESCRIPTIONS` 提供，26 项全覆盖。

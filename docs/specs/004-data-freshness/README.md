# Spec 004 — data-freshness（数据时效性修复）

状态: **done**

## 目标

修复指标数据滞后问题：能用官方源替换的一律替换（6 项，数据由 2025-08 更新到 2026-08），无法替换的 3 项在界面显式标注滞后月数，避免读者误读；同时补齐指标卡缺失的口径说明。

非目标: 不引入付费数据源（Wind/Choice）；不自建统计局爬虫；不为滞后项编造数据。免费源穷尽性评估见 `design.md`。

## 交付

- 数据源替换 6 项 + 新增「消费者信心指数」（指标数 25 → 26）
- 时效判定（`isStale` / `lagMonths` / 各频率容忍度）+ 界面滞后标注
- 口径说明字典 `INDICATOR_DESCRIPTIONS`

# 008 — 需求

## 用户故事

### US-1 一级菜单收敛

作为使用者，我在左侧只看到一个「宏观经济」入口，点进去以后在顶部用二级菜单切换子模块，而不是在一级菜单里平铺三个并列项。

- **AC1**: 侧边栏移除「数据观察」分组标题，`国家经济数据 / 行业观察 / 跟踪提醒` 三项不再作为一级菜单项出现。
- **AC2**: 侧边栏新增单项「宏观经济」，指向 `/macro`；当路径为 `/macro`、`/industry`、`/alerts` 中任意一个时该项均判定为激活态（高亮）。
- **AC3**: 侧边栏最终结构为「工作台 / 宏观经济 / 设置」三项，无分组标题。

### US-2 顶部二级菜单

作为使用者，我在「宏观经济」下的任意子页顶部都能看到同一套二级菜单，可直接横向切换，且当前所在子页有明确选中态。

- **AC1**: `/macro`、`/industry`、`/alerts` 三页均在顶栏下方渲染二级菜单，三项标签依次为「国家经济数据」「行业观察」「跟踪提醒」。
- **AC2**: 二级菜单位置与样式在三页完全一致（同一布局组件渲染，非各页自行实现）。
- **AC3**: 当前路径对应的项显示选中态（强调色文字 + 下划线），其余项为常态。
- **AC4**: 二级菜单为纯导航，不做数据请求；切换为客户端路由跳转，不整页刷新。

### US-3 消除指标重复

作为使用者，同一批指标不应该在两个页面重复出现。

- **AC1**: `/macro` 只渲染 8 个宏观分组（总量与增长、消费与投资、对外贸易、价格、货币与金融、信心先行、房地产、汇率与外储），共 **26 项**，不再出现 `industry` 分组的「行业景气与高频」区段。
- **AC2**: `/industry` 仍只渲染 `industry` 分组，共 **10 项**。
- **AC3**: 两页的指标计数文案与各自实际渲染数量一致（26 / 10），首页「国家经济数据」卡片文案亦为 26 项。
- **AC4**: `staleCount`（数据源滞后计数）按各页自身可见指标范围统计，不把不可见分组的滞后计入。
- **AC5**: `GET /api/macro/indicators` 契约不变，仍返回全量 36 项（API 是数据接口，不受页面分层影响）。

### US-4 跟踪提醒自述

作为使用者，我第一次进入「跟踪提醒」时不知道这个模块是干什么的，希望能就地看到一句解释。

- **AC1**: `/alerts` 顶部统计条上方有一句说明，交代：规则为代码预置、对已入库指标最新数据实时判定、不推送通知。
- **AC2**: 说明文案与 spec 002 规则表口径一致（阈值 / 异动 / 剪刀差三类判定）。

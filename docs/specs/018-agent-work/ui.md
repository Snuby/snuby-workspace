```

│ Topbar（模块级，沿用创作中心）                                  │

│ 【作品条】 当前作品 ▾          [新建作品]                      │
```

## 2. 作品切换（并入模块顶栏）

顶栏布局：`作品创作` + 面包屑 `创作中心` | **加长的当前作品 ▾** |（状态）| 右侧蓝色 **+ 新建作品**。

### 2.1 当前作品

- 展示：作品标题（过长截断）；无作品时占位「选择或新建作品」。  
- 触发器加宽（约 `min(440px, 48vw)`），点击 → 打开 **作品切换面板**（下拉/浮层，非跳转页）。
- 新建作品：顶栏右侧 accent 实心按钮，带 Plus 图标。

### 2.2 作品切换面板

布局：

```
┌──────────────────┬────────────────────────────┐
│ 目录树            │ 预览区                      │
│ 📁 专栏A          │ 标题 / 路径面包屑             │
│   📁 子辑         │ 当前稿 content.md 只读预览    │
│     📄 作品X  ←选中│ （Markdown 渲染或源码二选一，  │
│   📄 作品Y        │  默认渲染）                   │
│ 📄 未分类作品Z     │                              │
│                   │                              │
│ [+ 新建文件夹]     │              [切换到此作品]   │
└──────────────────┴────────────────────────────┘
```

交互：

| 操作 | 行为 |
|---|---|
| 点击文件夹 | 展开/折叠；不切换当前作品 |
| 点击作品行 | 仅更新右侧预览（**不切换**工作区，避免误触丢上下文） |
| 点击「切换到此作品」 | 见 §2.4；关闭面板 |
| 双击作品行 | 等同「切换」（可选加速手势，MVP 可做） |
| 新建文件夹 | 弹名；挂到当前选中文件夹下（未选则根） |
| 拖拽（可后置） | 作品/文件夹移动；MVP 可用「移动到…」菜单 |

空态：无作品时树空 + 引导「新建作品」。

### 2.3 新建作品对话框

字段：

- **名称**（必填）  
- **放置目录**（树选择器，默认上次目录或根）  
- 类型：MVP 固定文章，可不展示或只读  

确定：创建 work 目录 → 挂到库索引对应文件夹 → **立即切换**为当前作品 → 关闭对话框与切换面板。

### 2.4 切换作品守卫

若当前作品：

- 编辑器 **dirty** → 对话框：保存 / 不保存 / 取消  
- 本作品 task **running/queued** → 允许切换视图（零网关），但提示「后台任务仍在排队/运行」；**禁止删除**该作品（已有 409）  
- 切换成功：工作区绑定新 workId；资源预览壳关闭；稿件/发布选中态重置

## 3. 工具区

可扩展工具槽；MVP 两个：

### 3.1 工作视图切换

分段控件：**稿件创作** | **发布**

- 只改工作区模式，不改 `currentDraftId`  
- 脏稿未保存切到发布：允许（发布默认基于磁盘 current）；若 dirty，条上弱提示「未保存修改不会进入发布，请先保存」  
- 视图状态可记在前端或 `meta.ui.lastView`（可选持久化）

### 3.2 当前稿件切换

触发器展示：当前稿短标签（如「当前 · 基于 d3」或时间/label）。

下拉：**版本树可视化**（与 `drafts-branches.json` 同构）

- 节点：label / 时间 / source  
- 高亮 current  
- 点选节点 → **checkout**（只改指针）；若编辑器 dirty → 先守卫（同 §2.4）  
- 树旁可只读预览该版正文（可选，与作品面板类似；MVP 可省略，切后中栏加载）

不在此做「保存」——保存在中栏底栏。

## 4. 稿件创作视图（三栏）

```
┌────────────┬─────────────────────┬──────────────────┐
│ 资源目录    │ Markdown 编辑器      │ Agent 编辑区      │
│            │ 顶栏工具条           │ 消息流            │
│            │ 正文                 │                  │
│            │ 底栏信息+保存        │ 底栏：附件+工具+发送│
└────────────┴─────────────────────┴──────────────────┘
        │
        └ 「+」或点资源 → 右侧弹出统一「资源侧栏」（添加 / 预览共用）
```

### 4.1 左栏 · 资源目录

- 列表：`resources.json` 条目（图标区分 url / 文本 / 图片）  
- 标题右侧**仅保留「+」**：打开资源侧栏的「添加」模式  
- 亦可拖入文件到资源列；白名单与 API 一致（非白名单 → toast 拒绝）  
- 点击条目：打开同一侧栏的「预览」模式（点遮罩 / 关闭关闭）  
- 不占用通用 `PreviewModal` 全屏模式

### 4.2 资源侧栏（添加 / 预览共用）

自上而下三区（**无资源 Agent 对话 UI**；解读走预设能力，历史仍可落 `collab/resources/<rid>.jsonl`）：

```
┌──────────────────────────────────────┐
│ ① 工具栏（对齐通用预览：后退/前进/地址/复制/外开/关闭） │
├──────────────────────────────────────┤
│ ② 预览栏（url / 图 / md / 文本 / html…）              │
│    添加模式时此处为「加链接 / 选本地文件」              │
├──────────────────────────────────────┤
│ ③ 信息 + AI 便捷工具                                   │
│    · 资源名 / kind / 路径                              │
│    · 「一键解读」按钮组：左触发解读；右上拉菜单           │
│      └ 编辑预设 Prompt（可还原系统默认）                │
│    · note 状态指引（已有 / 暂无）+ 预览 / 手动修改       │
└──────────────────────────────────────┘
```

- ①：与 LinkPreview / 通用预览工具组同构；非 web 资源时地址栏显示路径或名称  
- ②：复用作品内资源预览（桌面宽度 webview，避免移动断点）  
- ③：一键解读调用 `analyze-url` / `resource-note`，结果写入资源 note；不切换右栏稿件 Agent 历史  
- 侧栏可拖左缘调宽；添加成功后自动切到该资源预览

### 4.3 中栏 · Markdown 编辑器

- 顶：常见 md 工具条（粗斜体、标题、列表、链接、图片插入→插入 `resources/…` 路径）  
- 中：当前稿 `content.md` 缓冲编辑  
- 底：字数/dirty 态、**保存**（调 draft/save + baseline）  
- 不在此直接调 Agent 改稿（改稿在右栏）；保存与版本图规则见 design  

### 4.4 右栏 · 稿件 Agent

与本地 Agent 差异：

- **顶栏工具下移**到输入区下方，与「添加文件」同一行（模型/权限/停止等按本地 Agent 能力子集排布）  
- 消息流占满上方  
- 添加文件 → 写入本 work `resources` 并可选附带本轮 `resourceIds`  
- 历史：**稿件协作作用域**（全作品一份，见 §6）  
- 默认 capability：`general`；显式「改当前稿」可切 `edit-draft`（或发送时带意图；MVP 可用工具条切换模式）  
- 连接：共用全局；展示已连接即可，不在作品页重复「发现网关」大段（可链到设置/本地 Agent）

## 5. 发布视图（三栏）

基于**磁盘当前稿件**（或工具区所选 current）做发布编辑。

```
┌────────────┬─────────────────────┬──────────────────┐
│ 发布列表    │ 发布预览（只读于人）  │ Agent 编辑区      │
│ + 新建      │ 仅 Agent 可改产物   │ 发布作用域历史    │
│ 删除/选中   │ 每项一份，无版本树  │                  │
└────────────┴─────────────────────┴──────────────────┘
```

### 5.1 左栏

- 列表：`publish/*` 中 `status=ready`（及可选 staging 标记）  
- 新建：选平台 + 从当前 draft 生成空壳/触发 prepare（MVP 可先建 meta + 占位 content）  
- 删除：确认；busy 时禁用  

### 5.2 中栏

- 渲染选中发布项产物（html/md/图文结构）  
- **用户不可编辑**；无草稿版本树  
- Agent 改的是这一份；保存即落盘该 publish 目录（经 staging 规则）

### 5.3 右栏

- 同稿件 Agent 的控件布局  
- 历史：**当前选中发布项**独立一份（`collab/publish/<pubId>.jsonl`）；切换发布项即切换右栏历史  
- 无选中发布项时右栏禁用发送，空态提示「请先选择或新建发布项」  
- 发送默认 `publish-prepare`，`extras.pubId` + platform  
- **不**新建 ACP 会话：仍占用本作品唯一逻辑任务 / 网关绑定（见 §6）

## 6. Agent 历史作用域 vs ACP 会话（易错点）

### 6.1 两层必须分开

| 层 | 粒度 | 说明 |
|---|---|---|
| **ACP / 逻辑任务** | **每作品恰好一个** | `TaskKey=task:work:<workId>`；`meta.acpSessionId`；全局锁按 work；切换作品才换逻辑上下文并对齐网关 |
| **历史落盘 + UI 对话流** | 多 scope | 只决定「读哪份 jsonl / 往哪追加 / 预加载摘录哪段」；**不是**多套 ACP 会话 |

切资源壳、切稿件栏、切发布项、改 capability：**不** `session/new`，**不**换 TaskKey。  
仅当用户**切换到另一作品**（或重连丢绑定）时，才发生作品级 align / 全量预加载切换。

同作品内从「稿件 Agent」发一条再在「某资源壳」发一条：串行占用同一 work 锁；第二次 run 的 preload 用 **resource 历史摘录** + 点名该资源，但网关仍是该 work 已对齐的同一 ACP 会话（`same_task_continue` 或因逻辑 marker 仍是本 work 而走短提醒——**不得**因换 scope 误判为 `switched_task`）。

> `switched_task` **仅**当 `lastAlignedTaskKey` 的 workId（或 kind）变化。  
> scope 变化 → 记入 RunRequest / capability_addon / 历史路径，**不**触发 switched_task。

### 6.2 Scope 一览

| 界面位置 | Scope 键 | 历史路径 | 条数关系 |
|---|---|---|---|
| 资源协作预览壳右侧 | `resource` + `resourceId` | `collab/resources/<rid>.jsonl` | ≈ 资源数 |
| 稿件创作 · 右栏 | `draft` | `collab/draft/messages.jsonl` | 每作品 1 |
| 发布视图 · 右栏 | `publish` + `pubId` | `collab/publish/<pubId>.jsonl` | ≈ 发布项数 |

删除资源 / 发布项：同步删除（或归档）对应 jsonl。

### 6.3 UX 含义 + 软隔离（方案 A）

- 界面上像「多个对话窗口」，本质是 **同一作品 Agent 的多条记忆轨道**。  
- 预加载：L0/L1 工作区地图仍按 **作品** 注入；`history_snippet` **只抽出当前 scope**；每轮带短声明「本轮只处理当前 scope」（design §5.4 方案 A）。  
- 切换作品：整作品对齐；各 scope 文件留在原目录。

### 6.4 同作品单 flight（UI）

- 同一作品任一 Agent 栏（稿件 / 资源壳 / 发布）进入 running 或本作品 queued 占锁时：其余栏 **禁用发送**，文案「作品内任务进行中」。  
- 与全局跨作品/会话排队不同：同作品不展示「取消排队进另一栏插队」——必须等当前结束或停止。  
- 切到其他作品的发送仍走全局队列（前序可为作品《本篇》）。

## 7. 交互细节补全

### 7.1 空态

| 场景 | 处理 |
|---|---|
| 无作品 | 作品条占位 + 工作区居中 CTA「新建作品」 |
| 有作品无资源 | 左栏空态 + 拖入提示 |
| 新稿无字 | 中栏占位「开始写作或让右侧 Agent 起草」 |
| 无发布项 | 左栏空 +「从当前稿新建发布」 |

### 7.2 运行中反馈

- 见 §6.4：同作品单 flight；跨作品/会话才出现「排队中（前序：…）」  
- 资源壳打开时稿件栏若本作品已 running → 禁用发送（非入队到另一 scope）

### 7.3 可访问与误触

- 删除资源/发布/作品：确认框  
- 面板 Esc 关闭；有选中预览未切换不改 work  

### 7.4 与本地 Agent 并存

- 连接状态共享  
- 本地 Agent 跑任务时，作品发送排队（前序：会话「…」）  
- 反之亦然

## 8. 对底层方案的调整（相对 design.md v0.6）

### 8.1 必须改（P0）

**A. 作品库 / 文件夹树（原方案无）**

- 在 `agent-works` 之上增加 **库索引**（推荐）：  
  `agent-works/library.json`（或 `catalog.json`）描述文件夹树与 workId 挂载；**作品实体目录仍扁平** `agent-works/<workId>/`，避免文件夹重命名导致路径级联。  
- API：`GET/PATCH /api/work/library`；创建作品带 `folderId`；移动/建文件夹。  
- `meta` 可冗余 `folderId` 便于修复。

**B. 多 scope 消息（历史轨道；ACP 仍作品级）**

```
agent-works/<workId>/
  collab/
    draft/messages.jsonl
    publish/<pubId>.jsonl          # 每发布项一份
    resources/<resourceId>.jsonl   # 每资源一份
```

- `POST .../run`：`scope: "draft"|"publish"|"resource"` + `resourceId?` + `pubId?`（publish 必填）  
- 读写消息 / 预加载摘录按 scope；**TaskKey / acpSessionId / switched_task 只认 work**  
- 删资源或发布项时清理对应 jsonl  

**C. Capability 与 UI 对齐**

- 资源壳默认 `resource-note` / `analyze-url`（按 kind）  
- 稿件右栏 `general` | `edit-draft`  
- 发布右栏 `publish-prepare`  
- path-policy 已覆盖；补 `resource-note` 写 note 经 Service  

**D. 发布中栏「人只读、Agent 可写」**

- UI 禁用编辑；Agent 写 publish staging 已有矩阵  
- 明确：发布项**无** drafts 版本树（与 design 一致，UI 不再暗示版本）

### 8.2 建议改（P1）

- `meta.ui`：`lastView`, `lastPubId` 等，减轻刷新丢态  
- 库树与 listWorks 合并接口，减少面板打开往返  
- 资源预览壳布局 breakpoints（窄时 Agent 叠到底部）

### 8.3 不必改

- TaskKey / 全局单锁 / 切换零网关 / draft 版本图 / dirty 与 baseline / resources revision / conventions 渐进披露  
- 「连接全局共用」与 Runtime 设计一致  

### 8.4 预加载披露微调

全量 L1 仍给作品级地图；`history_snippet` **仅当前 scope**。  
resource / publish 的 capability_addon 点名 `resourceId` / `pubId`。  
换 scope **不**重跑作品级全量约定（除非同时满足 switched_task 等作品级 reason）。

## 9. MVP UI 范围建议

**做：** 作品条+库树+预览切换、新建作品、视图切换、稿件树 checkout、三栏稿件（资源 CRUD/壳简化版、编辑器保存、右栏 Agent draft scope）、发布三栏骨架（列表+只读预览+**按 pubId 历史**的 Agent）、连接态复用  

**可简：** 库内拖拽、版本树旁预览、资源壳精美分栏响应式、发布平台精调  

**不做：** 移动端布局、多窗同步 dirty、**按 scope 分裂 ACP 会话**  

---

## 10. 验收（UI 向，补 requirements）

- AC-U1：面板内点选作品只预览，点「切换」才换当前作品  
- AC-U2：dirty 切换作品/稿件有守卫  
- AC-U3：资源壳对话写入 `collab/resources/<rid>.jsonl`，不影响 draft 历史  
- AC-U4：稿件历史与各发布项历史、各资源历史两两隔离；切发布项右栏历史跟着变  
- AC-U5：本地 Agent 已连接时作品页显示已连接且可直接发送（网关可用时）  
- AC-U6：同作品内仅切换 scope 发送时，日志 **不得** 出现 `reason=switched_task`（除非中间切过其他 TaskKey）  
- AC-U7：同作品一栏 running 时，其他栏无法发出第二个 run（单 flight）
